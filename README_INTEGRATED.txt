CROREPATI LIVE 2026 — INTEGRATED OLLAMA EDITION

This is your complete uploaded Crorepati app. Ollama generation is inside its
existing Exam Syllabus screen. Saved questions also appear in Preserved Bank.
One app, one server, one START_WINDOWS.bat; no separate generator port.

UPDATE YOUR EXISTING APP
1. Close the old Crorepati terminal.
2. Extract this ZIP into D:\New folder (68). It contains Crorepati_Live_2026.
   Allow replacement of program files in that existing folder. Keep user-data.
3. Double-click START_WINDOWS.bat inside Crorepati_Live_2026.
The browser opens http://localhost:4173/syllabus when the app is ready.
If first-time onboarding appears, complete it, then select Exam Syllabus.
Node.js 22+ and your installed Ollama model are required; no npm install needed.

USE
The model field defaults to gemma3:4b. If your installed model has another name,
enter its exact name and click Generate all exams / Resume.
Select Exam > Subject > Chapter > Topic to see saved MCQs and source links.
Questions also appear in the app's Preserved Bank, with searchable review labels.
New AI drafts can be answered directly in syllabus/bank screens. They do not
become verified practice questions without review.
Click Download ZIP in the app to export questions and chapter files together.
No cloud API tokens are used by the integrated Ollama generator.

SAVING
Everything saves under the app folder on your hard drive:
user-data/factory — checkpoints and topic banks
deliverables/Ollama_40 — exam / subject / chapter JSON files
Pause finishes the current batch. Keep the terminal open while generating.
Reopen the same launcher after interruption. An explicit Pause remains paused.
Existing usable questions count toward 40 total per mapped topic. Shared topics
are generated once and reused for exams. New questions remain pending review.
Insufficient evidence is reported as a gap rather than fabricated filler.
The current syllabus mapping contains outlines and is not certified exhaustive.
Speed depends on your computer; generation can take many hours.

SI REMOVAL
Detected SI/physical-unit questions are removed from shipped banks. Changed
originals are retained in backups. The first Windows start also cleans existing
local banks with a backup. Browser-cached practice questions are filtered too.
Text matching can miss indirectly worded unit questions.

The ZIP contains prebuilt application files plus source. It does not contain
newly generated questions pretending to have run on your PC. Generation runs
locally when you launch the app. Windows-specific execution requires your PC.
