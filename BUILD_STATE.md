## Option-balance repair — 2026-10-16

The reported defect: the correct option was often conspicuously longer than the
distractors, so the answer was guessable without knowing the fact.

Measured on all 939 questions, taking the **worst of the English and Hindi** option
lengths (that is what a learner actually sees):

| ratio (correct / mean distractor) | before | after |
|---|---|---|
| >= 5.0 | 52 | 3 |
| >= 4.0 | 106 | 16 |
| >= 3.0 | 197 | 80 |
| >= 2.0 | 347 | 194 |
| >= 1.5 | 511 | 365 |
| clean (< 1.5) | 428 | 574 |

Mean combined ratio 2.10 -> 1.57.

What was done:

1. `build_curriculum/audit_option_balance.py` — measures the ratio and bins it.
2. `build_curriculum/balance_question_options.py --apply` — trimmed trailing
   elaboration from 100 English correct options (mean 57 -> 20 chars), appending the
   removed wording to `detailedExplanation` so nothing is lost.
3. `build_curriculum/harappan/balance_overrides.py` +
   `build_curriculum/apply_option_overrides.py --apply` — 54 authored parallel-option
   rewrites for the worst Harappan questions. Option ORDER is preserved, so no
   `correctIndex` moved. Mean ratio 5.04 -> 1.22.
4. `build_curriculum/balance_hindi_options.py --apply` — 72 trims of verbose Hindi
   correct options (mean 2.93 -> 1.19).
5. `build_curriculum/normalize_hindi_options.py --apply` — 63 head-noun-aware
   reductions anchoring the Hindi option to its terser English twin. Rejects broken
   fragments (a Hindi option cannot begin with `की`, `युक्त`, `सहित`, ...) and
   contrastive clauses (`जबकि`, `किंतु`), which are explanation, not option text.

Two latent defects were found and fixed on the way:

* `Q_S10-C64dfa5ec-T5c4c78bc_01` had **two options reading `4°C`**, one of which was the
  key. Pre-existing, not caused by the balancing. Option C is now `-4°C`.
* Three Hindi options carried **untranslated English glosses** that inflated the correct
  option (`10⁻¹⁵ (Ten raised to the power minus 15)`). Now plain `10⁻¹⁵`.
